# 3D Cameras (Xogot 3D Tutorial)

This project contains the example scenes used in the **Xogot 3D Modular Series - Introduction to Cameras** tutorial by **Erin Uptegrove**.

It demonstrates how to add and configure a **Camera3D** in **Xogot** — the iPad and iPhone port of the Godot Engine — and covers the essential camera settings needed to preview and play a 3D scene.

The project includes sample scenes that show how cameras interact with lighting and environments, how to view the scene through an active camera, and how different projection modes affect the look and feel of a game.

---

## Features

* Add and configure a **Camera3D** in a 3D scene
* Use a **Marker3D** as a camera pivot or rig for easier positioning and movement
* Preview the game through the camera view
* Set and switch the active camera
* Parent the camera to a player or scene object
* Configure camera **Cull Mask** layers to control visibility
* Compare **Perspective**, **Orthogonal**, and **Frustum** projection modes
* Adjust **Field of View**, **Size**, and **Near/Far** clipping ranges
* Explore camera-related **Window and aspect ratio** settings in Project Settings
